# QREX v0.1.2 — Privacy, Stability and Platform Readiness

Continuing improvements to the QREX QR scanner and creator for Android and iOS.

### Improvements
- Added **Developed by Brendigo** under **More → About**, with a link to brendigo.com.
- Added a readable offline privacy policy to Settings, with a public online version.
- Added a recovery screen for unavailable local preferences at application startup, with a retry action.
- Android targets API 36 and disables automatic app backups and app cleartext HTTP traffic.
- iOS includes a privacy manifest and camera/photo-picker purpose strings.
- CI verifies platform configuration and builds Android APK/AAB artifacts and an unsigned iOS app.

### Privacy and publishing
- No user accounts, built-in analytics or advertising services.
- QR contents are processed locally; external links are opened only by an explicit user action.
- GitHub Android APKs are test release builds, not signed with a production Play upload key.
- An iOS build requires Apple Developer signing to produce an installable IPA.

### Remaining QA
Static analysis and successful builds do not guarantee 1:1 match with a visual reference, crash-free operation on all devices or acceptance into the stores. Follow the [store checklist](../STORE_CHECKLIST.md) and test on physical phones before submission.
