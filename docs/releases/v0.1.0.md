# QREX v0.1.0 — First Public Release

**Scan. Create. Share.** Everything essential for QR codes, without unnecessary steps.

### Highlights
- Camera QR scanning and photo import, with torch and camera zoom where supported.
- Create QR codes for URLs, text, Wi-Fi, contacts, email, phone numbers, locations and events.
- Preview QR contents before opening a link; copy, share or save a result.
- Local searchable history and favorites with deletion controls.
- QREX's midnight-blue identity, blue-to-purple accents, optional light theme and custom launcher icon.
- No sign-in, ads, analytics or proprietary backend.

### Downloads
- **QREX-Android-v0.1.0.apk** — test release created by GitHub Actions. It uses development signing and **is not a Play Store-signed release**.
- **SHA256SUMS.txt** — APK checksum.
- **iOS:** a successful unsigned build was verified; an installable IPA requires Apple signing and provisioning.

### Release limitations
This initial development release still requires screenshot-to-reference visual comparison and tests on physical Android and iOS devices. Historic design illustrations were conceptual, not screenshots of running applications.
