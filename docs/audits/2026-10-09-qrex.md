# QREX Source Code, Privacy and Stability Audit

**Date:** October 9, 2026  
**Scope:** Public Flutter reference (v0.1.3) and separate Kotlin/Jetpack Compose and Swift/SwiftUI application projects.

This audit records code review and automated checks. It **does not certify** pixel-perfect design parity or prove an app can never crash.

| Area | Finding / change |

## Privacy and security findings

- QR scanning and generation are handled locally; no sign-in, ads, analytics or custom backend are included.
- Android requests camera access; image selection uses the OS picker without general media-library permission.
- iOS includes a privacy manifest and uses AVFoundation, PhotosPicker and Vision.
- External HTTP(S) links are opened only through a user-initiated action; the app does not verify a site's trustworthiness.
- Wi-Fi QR codes are not placed in automatic scan history. Users are warned before manually saving passwords.
- **Mitigated in platform projects:** Wi-Fi payloads are AES-GCM protected with Android Keystore; iOS saves history in the device-only Keychain. A failed migration drops only unsafe Wi-Fi entries rather than retaining plaintext. Physical-device validation and migration testing are still necessary.
- **Open risk:** Local data migration from the existing Flutter app to separate platform implementations is not completed. Replacing the installed app prematurely could lose history.

## Remaining requirements before replacing the current release

- [ ] Both current-platform builds and unit tests complete without errors after localization.
- [ ] XCTest runs on a booted iOS simulator with the complete localization bundle.
- [ ] QR feature parity across both platforms, including export, sharing, torch and zoom controls.
- [ ] Test permission denial, camera restart, backgrounding and large gallery images.
- [ ] Commit real app screenshots captured from emulators/simulators; inspect them against the design.
- [ ] Protect stored secrets; complete local data migration and store signing/review requirements.
- [ ] Smoke-test representative physical Android devices and iPhones.

**Merge policy:** Never replace the verified v0.1.3 public download solely because a new source branch compiles. Production readiness requires complete feature parity, realistic QA and privacy sign-off.
